# Neon Nexus

A decentralized chat application built with modern web technologies.

## Overview

Neon Nexus provides a peer-to-peer messaging platform with end-to-end encryption and decentralized identity management.

## Tech Stack

- React + TypeScript
- Bun runtime
- Tailwind CSS
- Decentralized networking protocols

## Getting Started

```bash
# Install dependencies
bun install

# Run development server
bun dev

# Build for production
bun build
```

## Features

- Real-time messaging
- Decentralized identity
- Encrypted communication channels
- Cross-platform support
